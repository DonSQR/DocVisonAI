## 操作步骤

### 1. Android Studio 中同步项目

打开项目后，点击 **File → Sync Project with Gradle Files**（或工具栏上的大象图标）

Android Studio 会自动从 JitPack 下载：
- `com.github.tbruyelle:RxPermissions:v0.9.3`
- `com.github.donkingliang:ImageSelector:2.2.0`
- `com.github.steve1316:opencv-android-sdk:4.12.0`

### 2. 构建 APK

点击 **Build → Build Bundle(s) / APK(s) → Build APK(s)**

或运行：
```bash
./gradlew clean :app:assembleDebug
```

APK 生成位置：`app/build/outputs/apk/debug/app-debug.apk`
