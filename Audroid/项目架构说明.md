# 项目架构说明

## 1. 应用概述

这是一个**文档扫描与增强处理**的 Android 应用（包名 `com.example.conference`），主要功能是：

1. **拍照/选图** — 从相册选图或拍照导入文档图片
2. **文档提取** — 通过传统图像处理或深度学习方法，从图片中提取文档区域
3. **去摩尔纹** — 使用深度学习模型去除扫描图片中的摩尔纹
4. **导出 PDF** — 将处理后的文档拼接成 PDF 文件

---

## 2. 软件架构

### 2.1 导航结构

应用采用 **BottomNavigation + Navigation Component** 的三页面结构：

```
MainActivity (AppCompatActivity)
 ├── BottomNavigationView
 │    ├── [选择图片] ── SelectFragment
 │    ├── [处理图片] ── HandleFragment
 │    └── [PDF导出] ── PdfFragment
 └── 选项菜单 (Menu)
      ├── 传统方法提取文档
      ├── 深度学习方法提取文档
      ├── 去摩尔纹 (开关)
      └── 重置应用
```

### 2.2 页面功能

| 页面 | Fragment | 功能 |
|---|---|---|
| **选择图片** | `SelectFragment` | 从相册选择图片、拍照、预览、排序、删除 |
| **处理图片** | `HandleFragment` | 对选中图片进行文档提取、边缘检测、去摩尔纹 |
| **PDF导出** | `PdfFragment` | 查看已处理的 PDF 文件列表 |

## 3. 运行逻辑

### 3.1 图片选择流程

```
用户点击悬浮按钮
  └→ SelectPicPopupWindow 弹窗 (拍照 / 从相册选择)
       ├─ [拍照] → 请求相机权限 → 系统相机 → 返回图片
       └─ [相册] → ImageSelector 多选器 → 返回图片列表
       
图片进入 SelectFragment 的 GridView 展示
用户可：预览大图、长按排序/删除、确认选择
确认后 → 跳转到 HandleFragment
```

### 3.2 图片处理流程

```
HandleFragment 接收图片列表
  ├─ 用户通过菜单选择处理模式:
  │   ├─ [传统方法] → ExtractThread
  │   │     原理: 灰度→边缘检测(Canny)→轮廓查找→四边形拟合→透视变换
  │   └─ [深度学习方法] → DeepThread
  │        原理: U²-Net 分割→轮廓提取→四边形拟合→透视变换
  │
  ├─ 可选: [去摩尔纹] → DemoireUtils
  │      原理: ESDNet 深度学习模型去除摩尔纹
  │
  └─ 处理完成后:
       ├─ 保存图片到本地
       ├─ 可叠加 PDF 预览
       └─ 点击按钮导出 PDF
```

### 3.3 PDF 导出流程

```
用户点击"生成PDF"
  └→ HandleFragment 将处理后的图片
       ├─ 按顺序拼接
       ├─ 生成 iText PDF 文档
       └─ 保存到设备
       
PdfFragment 展示已生成的 PDF 列表
用户可：查看、删除、分享 PDF
```

## 4. 处理模式对比

| 模式 | 方法 | 优点 | 缺点 |
|---|---|---|---|
| **传统方法** | Canny + Hough + 四边形拟合 | 速度快，无需模型 | 对复杂背景效果一般 |
| **深度学习方法** | U²-Net 语义分割 | 泛化能力强，背景复杂也能处理 | 需要加载模型，速度较慢 |

## 5. 关键技术栈

| 技术 | 用途 |
|---|---|
| **Android Jetpack** (Navigation, AppCompat) | 页面导航、UI 框架 |
| **OpenCV 4.x** (C++ native) | 图像处理 (Canny、Hough、透视变换、轮廓提取) |
| **PyTorch Mobile** | 深度学习模型推理 (U²-Net、ESDNet) |
| **iTextPDF** | PDF 文档生成 |
| **Glide** | 图片加载与缓存 |
| **RxPermissions** | 运行时权限管理 |
| **ImageSelector** | 多图片选择器 |
| **PhotoView** | 图片手势缩放预览 |

## 6. 数据流

```
[相册/相机]
    ↓ 图片路径
[SelectFragment] → FinalImgList (全局图片列表)
    ↓ 确认选择
[HandleFragment] → ExtractThread / DeepThread / DemoireUtils
    ↓ 处理完成
[保存到设备存储] → /Conference/ 目录
    ↓
[PdfFragment] → 列出 PDF → 打开/分享
```

### 关键数据类

- **`FinalImgList`**：全局单例，维护两个图片列表
  - `finalSrcImgList`：原始选择图片
  - `finalImgList`：处理后图片
- **`Global`**：全局状态
  - `method`：处理模式 ("traditional" / "ai")
  - `useDemoire`：是否启用去摩尔纹
